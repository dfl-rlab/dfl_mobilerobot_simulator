# DFL Mobile Robot Simulator

## Overview

This repository brings together Gazebo simulation setups for exploring 3D mapping and autonomous navigation with the [dddmr_navigation](https://github.com/dfl-rlab/dddmr_navigation) stack. It offers a starting point for learning and experimenting without setting up everything from scratch.

## Available Simulations

Choose a robot below and follow its branch guide to build the Docker image and launch the simulation.
